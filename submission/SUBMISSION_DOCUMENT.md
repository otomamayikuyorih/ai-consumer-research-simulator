## 2. 対象ユーザーと解決する課題

### 対象ユーザー
- 新商品・新規事業を開発する企画・マーケティング担当者、ブランドマネージャー
- 広告代理店・リサーチ会社のプランナー・リサーチャー
- 被験者リクルーティングや調査費用の捻出が難しいスタートアップ・中小企業
- 社会科学・消費者行動論を研究する大学・研究機関

### 解決する課題
1. **調査納期と費用の膨大さ**: 
   - 従来の消費者アンケートやフォーカスグループインタビューには、2〜4週間の期間と数百万円のコストがかかります。新商品仮説を高速にPDCA検証（プロトタイピング）することが困難でした。
2. **被験者のアンケート疲労と不真面目回答**:
   - 人間の被験者パネルでは、謝礼目的の形骸化した回答や後半の適当な回答が発生し、データ品質の劣化が課題となっています。
3. **質的調査（定性インタビュー）のスケーラビリティ欠如**:
   - 定性インタビューはインサイトの宝庫である一方、1回1時間かかるためサンプルサイズが数十名に限られ、統計的定量調査との橋渡しが分断されていました。
4. **AI生成データの信頼性・ハルシネーション懸念**:
   - 従来の単なる「ChatGPTでのペルソナ作成」では、非現実的な属性組み合わせや母集団との乖離、回答の偏りが検証できず、ビジネスの意思決定に使えませんでした。

## 3. ソリューションと特徴

本プラットフォームは、電通の「People Model」「People Research」「AI For Growth Talk」の思想を発展させ、**日本の公的統計（国勢調査・就業構造基本調査・家計調査等）**の多変量結合分布と、**米スタンフォード大学 AI for Public Benefit Lab（AI4PB）およびNature誌（2026年）の最新研究成果**を取り入れた、自律型マルチエージェント消費者調査Webアプリケーションです。

#### 主要機能（全10モジュール）
1. **自律型調査オーケストレーター (Agentic Orchestrator)**: 自然言語で調査ゴールを入力するだけで、コホート生成 ➔ 設問設計 ➔ Gemini 3.5 Flash並行シミュレーション ➔ 多変量解析&戦略サマリー要約まで自律連鎖実行。各ステップのモデル名、稼働時間(ms)、リトライ履歴を可観測化。
2. **ダッシュボード & 公的統計検証**: システム全体のサマリー、ペルソナ属性分布、公的統計ベンチマーク検証、直近調査・実験ステータスの一覧。
3. **ペルソナ生成・統計検証**: 100〜1,000人の仮想生活者を3つの生成モード（Mode A: 人口統計 / Mode B: 合成リッチ / Mode C: 定性インタビュー根拠化）で生成。
4. **アンケート作成**: 単一選択、複数選択、5段階評価尺度、自由記述形式の設問を自由自在にビジュアル設計。
5. **調査シミュレーション**: 生成したペルソナ群に対し、Gemini 3.5 Flash を用いて超高速に並列回答シミュレーションを実行。
6. **結果解析・多変量解析**:
   - 単純集計、クロス集計、カイ二乗検定（有意差検定）。
   - 主成分分析 (PCA) によるブランド知覚マップ散布図。
   - K-Means クラスタリングによる自動生活者セグメンテーション。
   - 自由記述コメントの AI 要約・感情比率（ポジティブ/ニュートラル/ネガティブ）分析。
   - Excel対応 UTF-8 BOM付き個票生データ CSVダウンロード。
7. **仮想A/B実験 (Nature 2026)**: Control / Treatment 条件の提示順序をランダム化しプロンプトにも提示順を明示。Gemini 3.5 Flash による実ペルソナ推論と、平均差・割合差・効果量（Cohen's d）・対応のあるt検定を有意差検定（ルールベースはデモモードとして分離）。
8. **Zero-shot 折半サンプリング頑健性検証 (Human-AI Validation)**: 疑似乱数誤差を全廃。実測データを 50/50 に折半分割し、事後校正のないZero-shot推論による MAE、RMSE、Pearson 相関係数 $r$（計算不能時は N/A）で AI シミュレーションの予測精度を客観評価。
9. **AIインタビュー (1on1 Deep Talk)**: アンケート回答者の中から気になるペルソナを選択し、1対1で理由や生活背景を深掘りチャット。
10. **コンセプト評価 (商品受容性テスト)**: 新商品コンセプト案・価格・説明文を入力し、購入意向・価格受容性・利用シーン・改善提案を自動出力。

## 4. AIエージェントの特徴と自律的な動作

本システムは単なる質問応答型チャットボットではなく、**「自律的マルチエージェント・シミュレーション基盤」**として設計されています。

### 7つの自律型AIエージェント
1. **自律型調査オーケストレーター (Autonomous Research Orchestrator Agent)**:
   - リサーチャーの調査課題（ゴール）から、[コホート生成] ➔ [設問票自動設計] ➔ [Gemini 3.5 Flash並行回答] ➔ [多変量統計解析＆エグゼクティブサマリー要約] までを自律的に連鎖実行。各ステップのモデル名、所要時間(ms)、リトライ履歴を完全可観測化。
2. **統計ペルソナ生成エージェント (Persona Synthesizer Agent)**:
   - 日本の国勢調査・就業構造基本調査・家計調査等の統計相関に基づき、年齢・年収・居住地・家族構成・消費価値観などの現実的な組み合わせを自律サンプリング。
3. **インタビュー根拠化エージェント (AI4PB Grounding Agent - Mode C)**:
   - スタンフォード大学 AI4PB 研究に基づき、実際の定性インタビュー記録から7つの心理行動次元（価値観・消費行動・購買動機・価格感度・意思決定傾向・生活習慣・興味関心）と本人の生の発言（Verbatim Quotes）を抽出し、ペルソナの記憶基盤を自律構築。
4. **自律回答推論エージェント (Survey Responding Agent)**:
   - 各仮想生活者が独立したエージェントとして、自らの信念・ライフスタイル・過去回答との心理的一貫性を維持しながらアンケートを自律回答。
5. **仮想A/B実験エージェント (Virtual A/B RCT Agent - Nature 2026)**:
   - Nature 2026 論文の知見に基づき、実験群・対照群の提示順序によるアンカリングバイアスを相殺するためのランダム化（Counterbalancing）を実施し、Gemini 3.5 Flash による実ペルソナ評価と Cohen's d、対応のあるt検定を算出。
6. **Zero-shot 折半サンプリング頑健性検証エージェント (Empirical Validation Agent)**:
   - 疑似乱数誤差を全廃。人間の実測データを 50/50 に分割し、事後校正のないZero-shot推論として MAE、RMSE、Pearson $r$（計算不能時は N/A）を自動検証・可視化。
7. **1on1 定性深掘り対話エージェント (Qualitative Interview Agent)**:
   - 人間インタビュアーの質問意図を解釈し、ペルソナの生活文脈とアンケート回答履歴を参照して自律的に思考し、リアルな心理を語る。

## 5. 使用しているGoogle Cloudサービス

| サービス名 | 役割と選定理由 |
|---|---|
| **Google Cloud Run** | アプリケーションの実行環境。FastAPI と React SPA を統合した Docker コンテナをサーバーレスで実行。トラフィックに応じた 0〜N の自動スケーリングにより、**アイドル時のコストは完全無料（¥0）**。審査期間中も常時アクセス可能。 |
| **Google Gemini 3.5 Flash / Vertex AI** | 高速・高スループット・低コストな並列推論基盤。100〜1,000人のペルソナ生成、アンケート回答の一括バッチ推論、定性発言の忠実な抽出、1on1インタビュー対話エンジンとしてフル活用。 |
| **Google Cloud Logging** | エージェントの自律的意思決定ログ、推論レイテンシ、エラー監視を統合管理。審査基準である「可観測性（Observability）」を担保。 |
| **GCP Secret Manager** | Gemini APIキー等の機密情報を安全に管理・注入し、コードリポジトリへのクレデンシャル漏洩を完全防止。 |

## 6. ガバナンス・セキュリティ・倫理設計（ハッカソン重点テーマ）

1. **実在被験者データの厳格な同意管理（GDPR / 個人情報保護法準拠）**:
   - Mode C（定性インタビュー取り込み）では、調査参加者の本人同意確認フラグ（`consent_confirmed`）をデフォルト `False` に設定。同意チェックがない取込リクエストは API レベルで即時 400 Bad Request 拒否。
2. **審査用公開環境における実在個人データの改変・削除保護**:
   - Cloud Run 公開環境（`RESTRICT_PUBLIC_DATA_MODIFICATION=true`）では、実在個人データの新規アップロードおよび初期ベースデモデータの削除を 403 Forbidden で保護。
3. **Gemini API 失敗時のフェイルセーフと推論完全性**:
   - 万が一の Gemini API タイムアウトや失敗時には、モックへの自動切替を UI 上に明確に警告表示（`mock_fallback_warning`）。実AI推論データとして誤認・永続保存されることを防止。
4. **合成データと公的統計の明確な区分**:
   - UIの全ページに「公的統計に基づくAI合成シミュレーションであり、実在の母集団調査結果とは区別して解釈すること」を促す免責バナーとメタデータタグを常時表示。
5. **公的統計ベンチマークの引用元と仮定の明示**:
   - 総務省統計局『令和2年国勢調査』『令和4年就業構造基本調査』『2023年家計調査年報』、国税庁『令和4年分民間給与実態統計調査』の引用元・対象年および、6つの消費価値観セグメントの手動設定仮定を UI および README 上で開示。

## 7. 審査員向けの動作確認手順

1. **アクセス**: デプロイURL（またはローカル起動環境 `http://127.0.0.1:8000`）を開きます。
2. **ステータス確認**: 右上の「GCP Cloud Run / Gemini」ステータスバッジをクリックすると、`/api/status` の実行メタデータを確認できます。
3. **自律型調査オーケストレーター体験**: トップ画面の「自律型調査オーケストレーター」から、プリセットを選択して実行。エージェントが4工程（ペルソナ生成 ➔ 設問設計 ➔ シミュレーション ➔ 多変量解析&戦略サマリー）を自律連鎖実行する様子と Provenance を確認できます。
4. **ペルソナ生成 & 公的統計検証**: 上部メニュー「基本調査フロー」→「ペルソナ生成・検証」を開き、「公的統計ベンチマーク検証」ボタンを押すと、国勢調査等のデータとの分布一致度と手動設定仮定が確認できます。
5. **調査シミュレーション**: 「アンケート作成」またはプリセット調査から「調査シミュレーション」を実行。仮想生活者が一括で回答を生成します。
6. **多変量解析**: 「結果解析・多変量」で、棒グラフ、クロス集計＆カイ二乗検定、PCA散布図、K-Meansクラスタリング、自由記述AI要約を閲覧できます。
7. **AI4PB 学術実験**: 上部メニュー「AI4PB 学術実験・検証」から「仮想A/B実験」および「Human-AI検証」を開き、Nature 2026準拠の順序ランダム化実推論および実測データとの 50/50 折半頑健性評価を実行できます。
8. **AIインタビュー**: 「定性対話・商品評価」→「AIインタビュー」で回答者の一人を選択し、「なぜこの商品を選んだのですか？」と質問すると、生活背景に根ざした生々しい回答が返ってきます。
