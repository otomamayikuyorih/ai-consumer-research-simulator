## 2. 対象ユーザーと解決する課題

### 対象ユーザー
- 新商品・新規事業を開発する企画・マーケティング担当者、ブランドマネージャー
- 広告代理店・リサーチ会社のプランナー・リサーチャー
- 被験者リクルーティングや調査費用の捻出が難しいスタートアップ・中小企業
- 社会科学・消費者行動論を研究する大学・研究機関

### 解決する課題
1. **調査納期と費用の膨大さ**: 
   - 従来の消費者アンケートやフォーカスグループインタビューには、2〜4週間の期間と数百万円のコストがかかります。新商品仮説を高速にPDCA検証（プロトタイピング）することが困難でした。
2. **被験者のアンケート疲労と不真面目回答**:
   - 人間の被験者パネルでは、謝礼目的の形骸化した回答や後半の適当な回答が発生し、データ品質の劣化が課題となっています。
3. **質的調査（定性インタビュー）のスケーラビリティ欠如**:
   - 定性インタビューはインサイトの宝庫である一方、1回1時間かかるためサンプルサイズが数十名に限られ、統計的定量調査との橋渡しが分断されていました。
4. **AI生成データの信頼性・ハルシネーション懸念**:
   - 従来の単なる「ChatGPTでのペルソナ作成」では、非現実的な属性組み合わせや母集団との乖離、回答の偏りが検証できず、ビジネスの意思決定に使えませんでした。

## 3. ソリューションと特徴

本プラットフォームは、電通の「People Model」「People Research」「AI For Growth Talk」の思想を発展させ、**日本の公的統計（国勢調査・就業構造基本調査・家計調査等）**の多変量結合分布と、**米スタンフォード大学 AI for Public Benefit Lab（AI4PB）およびNature誌（2026年）の最新研究成果**を取り入れた、自律型マルチエージェント消費者調査Webアプリケーションです。

### 主要機能（全9モジュール）
1. **ダッシュボード**: システム全体のサマリー、ペルソナ属性分布、公的統計ベンチマーク検証、直近調査・実験ステータスの一覧。
2. **ペルソナ生成・統計検証**: 100〜1,000人の仮想生活者を3つの生成モード（Mode A: 人口統計 / Mode B: 合成リッチ / Mode C: 定性インタビュー根拠化）で生成。
3. **アンケート作成**: 単一選択、複数選択、5段階評価尺度、自由記述形式の設問を自由自在にビジュアル設計。
4. **調査シミュレーション**: 生成したペルソナ群に対し、Gemini 3.8 Flash を用いて超高速に並列回答シミュレーションを実行。
5. **結果解析・多変量解析**:
   - 単純集計、クロス集計、カイ二乗検定（有意差検定）。
   - 主成分分析 (PCA) によるブランド知覚マップ散布図。
   - K-Means クラスタリングによる自動生活者セグメンテーション。
   - 自由記述コメントの AI 要約・感情比率（ポジティブ/ニュートラル/ネガティブ）分析。
   - Excel対応 UTF-8 BOM付き個票生データ CSVダウンロード。
6. **仮想A/B実験 (Nature 2026)**: Control / Treatment 条件の提示順序をランダム化し、平均差・割合差・効果量（Cohen's d）・対応のあるt検定を有意差検定。
7. **Human-AI汎化検証 (AI4PB)**: 実測アンケートデータを 50/50（Calibration / Held-out Test）に自動分割し、MAE、RMSE、Pearson 相関係数 $r$ で AI シミュレーションの予測精度を厳密に客観評価。
8. **AIインタビュー (1on1 Deep Talk)**: アンケート回答者の中から気になるペルソナを選択し、1対1で理由や生活背景を深掘りチャット。
9. **コンセプト評価 (商品受容性テスト)**: 新商品コンセプト案・価格・説明文を入力し、購入意向・価格受容性・利用シーン・改善提案を自動出力。

## 4. AIエージェントの特徴と自律的な動作

本システムは単なる質問応答型チャットボットではなく、**「自律的マルチエージェント・シミュレーション基盤」**として設計されています。

### 6つの自律型AIエージェント
1. **統計ペルソナ生成エージェント (Persona Synthesizer Agent)**:
   - 日本の国勢調査・就業構造基本調査・家計調査等の統計相関に基づき、年齢・年収・居住地・家族構成・消費価値観などの現実的な組み合わせを自律サンプリング。
2. **インタビュー根拠化エージェント (AI4PB Grounding Agent - Mode C)**:
   - スタンフォード大学 AI4PB 研究に基づき、実際の定性インタビュー記録から7つの心理行動次元（価値観・消費行動・購買動機・価格感度・意思決定傾向・生活習慣・興味関心）と本人の生の発言（Verbatim Quotes）を抽出し、ペルソナの記憶基盤を自律構築。
3. **自律回答推論エージェント (Survey Responding Agent)**:
   - 各仮想生活者が独立したエージェントとして、自らの信念・ライフスタイル・過去回答との心理的一貫性を維持しながらアンケートを自律回答。
4. **仮想A/B実験エージェント (Virtual A/B RCT Agent - Nature 2026)**:
   - Nature 2026 論文の知見に基づき、実験群・対照群の提示順序によるアンカリングバイアスを相殺するためのランダム化（Counterbalancing）を自律実行し、Cohen's d と対応のあるt検定を算出。
5. **Human-AI汎化検証エージェント (Empirical Validation Agent)**:
   - 人間の実測ベンチマークデータを 50/50 に分割し、AIシミュレーションの汎化性能（MAE、RMSE、Pearson $r$）を自動検証・可視化。
6. **1on1 定性深掘り対話エージェント (Qualitative Interview Agent)**:
   - 人間インタビュアーの質問意図を解釈し、ペルソナの生活文脈とアンケート回答履歴を参照して自律的に思考し、リアルな心理を語る。

## 5. 使用しているGoogle Cloudサービス

| サービス名 | 役割と選定理由 |
|---|---|
| **Google Cloud Run** | アプリケーションの実行環境。FastAPI と React SPA を統合した Docker コンテナをサーバーレスで実行。トラフィックに応じた 0〜N の自動スケーリングにより、**アイドル時のコストは完全無料（¥0）**。審査期間中も常時アクセス可能。 |
| **Google Gemini 3.8 Flash / Vertex AI** | 高速・高スループット・低コストな並列推論基盤。100〜1,000人のペルソナ生成、アンケート回答の一括バッチ推論、定性発言の忠実な抽出、1on1インタビュー対話エンジンとしてフル活用。 |
| **Google Cloud Logging** | エージェントの自律的意思決定ログ、推論レイテンシ、エラー監視を統合管理。審査基準である「可観測性（Observability）」を担保。 |
| **GCP Secret Manager** | Gemini APIキー等の機密情報を安全に管理・注入し、コードリポジトリへのクレデンシャル漏洩を完全防止。 |

## 6. ガバナンス・セキュリティ・倫理設計（ハッカソン重点テーマ）

1. **同意管理とデータ削除API (GDPR / 個人情報保護法準拠)**:
   - 実在の調査参加者データを取り込むMode Cでは、本人の同意取得確認フラグを必須化。
   - `DELETE /api/interview-datasets/{id}` エンドポイントにより、同意撤回時に紐づくデータを完全抹消可能。
2. **合成データと公的統計の明確な区分**:
   - UIの全ページに「公的統計に基づくAI合成シミュレーションであり、実在の母集団調査結果とは区別して解釈すること」を促す免責バナーとメタデータタグを常時表示。
3. **Out-of-sample 実測検証によるハルシネーション抑制**:
   - AIの回答結果を盲信させず、実測データとの誤差（MAE / RMSE / 相関係数）をダッシュボード上で客観提示。

## 7. 審査員向けの動作確認手順

1. **アクセス**: デプロイURL（またはローカル起動環境 `http://127.0.0.1:8000`）を開きます。
2. **ステータス確認**: 右上の「GCP Cloud Run / Gemini」ステータスバッジをクリックすると、`/api/status` の実行メタデータを確認できます。
3. **ペルソナ生成**: 上部メニュー「基本調査フロー」→「ペルソナ生成・検証」を開き、「公的統計ベンチマーク検証」ボタンを押すと、国勢調査データとの分布一致度が確認できます。
4. **調査シミュレーション**: 「アンケート作成」またはプリセット調査から「調査シミュレーション」を実行。100人の仮想生活者が一括で回答を生成します。
5. **多変量解析**: 「結果解析・多変量」で、棒グラフ、クロス集計＆カイ二乗検定、PCA散布図、K-Meansクラスタリング、自由記述AI要約を閲覧できます。
6. **AI4PB 学術実験**: 上部メニュー「AI4PB 学術実験・検証」から「仮想A/B実験」および「Human-AI検証」を開き、Nature 2026準拠のランダム化RCT検証および実測データとの 50/50 held-out 汎化評価を実行できます。
7. **AIインタビュー**: 「定性対話・商品評価」→「AIインタビュー」で回答者の一人を選択し、「なぜこの商品を選んだのですか？」と質問すると、生活背景に根ざした生々しい回答が返ってきます。
