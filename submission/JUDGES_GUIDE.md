## 2. 5分で体験できる推奨検証シナリオ

### シナリオ⓪: 自律型調査オーケストレーターの1クリック自律実行 (約45秒 - 最もエージェントらしさを体感可能)
1. トップ画面（ダッシュボード）中央の **「自律型調査オーケストレーター (Agentic Orchestration)」** カードを確認します。
2. プリセットから **「スマートウォッチ健康受容性」**（または「フードロス削減エシカル定期便」）をクリックします。
3. 推論エンジンに **「Gemini 3.8 Flash」**（または高速デモモード）、サンプルサイズに **「30名」** を選択し、**「自律調査パイプラインを実行する」** をクリックします。
4. エージェントが以下の4工程を自律連鎖実行します：
   - **Step 1: 👥 統計代表ペルソナ群の自動生成**（国勢調査・就業構造・家計統計に基づくモンテカルロサンプリング）
   - **Step 2: 📝 調査課題からの設問票自動設計**（Gemini 3.8 Flash による4設問の動的設計）
   - **Step 3: 🤖 ペルソナ群による並行シミュレーション**（各ペルソナの一貫性を保った並行推論）
   - **Step 4: 📊 多変量統計解析＆エグゼクティブサマリー要約**（PCA/K-Means + Gemini 3.8 Flash 戦略提言）
5. 完了後、各ステップの **稼働モデル・所要時間(ms)・リトライ履歴 (Provenance)**、および Gemini が要約した **「エグゼクティブサマリー（主要発見・推奨ターゲット・戦略提言）」** が表示されます。「多変量解析ダッシュボードで詳細を見る」から即座にPCA知覚マップへ遷移可能です。

### シナリオ①: 公的統計に基づく自律ペルソナ生成と母集団検証 (約1分)
1. 上部メニュー **「基本調査フロー」▼** から **「ペルソナ生成・検証」** を開きます。
2. 生成人数で **「100人」** を選択し、**「ペルソナ群を生成」** をクリックします。
3. 生成完了後、**「公的統計ベンチマーク検証」** ボタンをクリックしてください。
4. モーダルが開き、生成された仮想生活者集団の年代分布・地方分布が、日本の公的統計（総務省統計局『令和2年国勢調査』『令和4年就業構造基本調査』『令和4年分民間給与実態統計調査』『2023年家計調査年報』）とどれほど合致しているかがグラフで可視化されます。
5. 手動設定した仮定（6つの消費価値観セグメント比率や情報接触チャネル）も透明性を持って明記されています。

### シナリオ②: 自律調査シミュレーションと多変量解析 (約1分)
1. **「基本調査フロー」▼** から **「アンケート作成」** を開きます。
2. プリセット調査「新スマートウォッチ受容性調査」が事前ロードされています（自由な設問の追加・編集も可能）。
3. **「調査シミュレーション」** へ進み、ペルソナコホートを選択して **「シミュレーション実行」** をクリックします。
4. Gemini 3.8 Flash により各ペルソナが自律回答し、即座に集計されます。
5. **「結果解析・多変量」** を開きます：
   - **単純集計**: 単一選択、5段階尺度の平均値・Top-2 Box、棒グラフ
   - **クロス集計**: 年代別・性別別・年収別のクロス集計表および **カイ二乗検定（$p$値判定）**
   - **多変量解析 (PCA)**: 主成分分析による2次元知覚マップ散布図
   - **クラスタリング**: K-Means による生活者自動セグメンテーション
   - **自由記述 AI 要約**: 感情比率（ポジティブ/ニュートラル/ネガティブ）とテキスト要約
   - **CSV エクスポート**: Excel対応 UTF-8 BOM付き個票生データを1クリックでダウンロード可能

### シナリオ③: 最新学術研究準拠の検証（仮想A/B実験 & Zero-shot頑健性検証）(約1.5分)
1. 上部メニュー **「AI4PB 学術実験・検証」▼** から **「仮想A/B実験」** を開きます。
2. 推論エンジンで **「Gemini 3.8 Flash (実推論)」** を選択し、**「実験シミュレーション実行」** をクリックします。
3. **Nature誌（2026年）論文**の手法に基づき、エージェントごとに提示順序をランダム化（Counterbalancing）し、プロンプトにも提示順序を明示注入。Control群とTreatment群の個別評価理由、平均差、効果量（Cohen's d）、対応のあるt検定（$p$値）が自動算出されます（ルールベース方式はデモモードとして分離）。
4. 続いて **「Human-AI検証」** を開きます。
5. 実在の人間アンケートデータを取り込み、**50/50 分割** による客観検証を実行。疑似乱数を完全排除し、事後校正を行わない Zero-shot 折半サンプリング頑健性検証として、MAE（平均絶対誤差）、RMSE、Pearson 相関係数 $r$（計算不能時は厳密に N/A 表示）により予測精度を客観測定します。

### シナリオ④: 1on1 定性深掘りインタビュー (約1分)
1. 上部メニュー **「定性対話・商品評価」▼** から **「AIインタビュー」** を開きます。
2. アンケートに回答したペルソナの中から、気になる人物（例: 60代自営業男性、20代会社員女性など）を選択します。
3. チャット欄で質問を入力します（例: 「なぜこの商品を購入したいと思ったのですか？」「価格についてどう感じますか？」）。
4. ペルソナは自身の生活背景、価値観、および先ほどのアンケート回答内容を参照し、心理的一貫性を持った生々しい言葉で返答します。

## 3. ガバナンス・セキュリティ・学術的誠実性の確認方法

- **同意管理とデータ削除**:
  - Mode C（実在インタビューの取り込み）では、調査参加者の同意確認フラグがデフォルト `False` であり、同意なしのインジェストは 400 Bad Request で拒否されます。
  - 同意撤回時は `DELETE /api/interview-datasets/{id}` APIにより、関連データが即座に完全抹消されます。
- **審査用公開環境におけるデータ改変・削除制限**:
  - 審査用 Cloud Run 公開環境（`RESTRICT_PUBLIC_DATA_MODIFICATION=true`）では、実在個人データの無断アップロードおよびデモデータの削除が 403 Forbidden で保護されます。
- **Gemini API 失敗時のフェイルセーフ**:
  - API 失敗時はモックへのフォールバック警告が表示され、本番 AI 推論データとして誤って集計・永続化されることを防止します。
- **公的統計の引用元と仮定の明示**:
  - 国勢調査、就業構造基本調査、民間給与実態統計調査、家計調査の調査名・対象年を明記し、6つの消費価値観セグメントなどの手動仮定を UI および README 上で開示しています。
- **コード・クレデンシャル安全確認**:
  - リポジトリ内には一切の秘密鍵・パスワードが含まれておらず、GCP Secret Manager および環境変数のみで安全に注入されています。
